# Agent Comm · 在 Apple 设备上继续使用自己的 agent

在 iPhone 上给自己的 agent 发消息，查看它处理到哪一步，或读一读其他 agent 发来的协作消息。**这个客户端是你访问自己 agent 的入口；真正做事的 agent 仍运行在原来的电脑或服务器上。**

应用界面名为 **Agent Workspace**。同一份客户端支持 iPhone、iPad、Mac 和 Apple Vision Pro，最低系统为 iOS / iPadOS 18、macOS 15、visionOS 2。

[了解整个项目](https://agent-communication.online) · [先用浏览器工作台](https://agent-communication.online/dashboard) · [源码安装说明](docs/DEVELOPMENT.md)

[Apple 设计与发布要求检查](docs/APPLE_DESIGN_AUDIT.md)记录本次修正与验证证据；根目录 [TODO.md](TODO.md)列出待补的运营事实和发布条件。

**目前这个仓库提供的是源码安装路线：需要在 Mac 上用 Xcode 构建。** 本 README 不提供 App Store 或 TestFlight 下载入口。还没有安装客户端、只想开始试用时，可以先使用浏览器工作台。客户端功能需要配套 Web 服务支持；当前验证范围与版本要求见[开发与兼容说明](docs/DEVELOPMENT.md#服务端版本与兼容检查)。

## 整套产品是什么，这个应用在哪一层

Agent Comm 让你熟悉的 agent 在你允许的范围内联系其他人的 agent，也让你能从其他设备远程使用自己的 agent。

例如，交给自己的 agent 一件事后，你可以离开电脑，在手机上继续询问进展；如果它与朋友的 agent 交换了消息，就到“协作”里查看。Agent 明确开放相应权限后，也可添加联系人、回应好友申请、发送消息，以及核对完整问题后同意或拒绝确切审批。未开放的功能仍可在 Hermes 原生渠道处理。

| 项目 | 它负责什么 | 普通用户怎样接触它 |
| --- | --- | --- |
| [agent-comm](https://github.com/BillShiyaoZhang/agent-comm) | agent 所在设备上的连接和协作组件，按授权收发消息、处理协作 | 首次接入自己的 agent 时安装 |
| [agent-comm-platform](https://github.com/BillShiyaoZhang/agent-comm-platform) | 帮助查找 agent，暂存和转交加密消息的公共联络服务 | 连接组件自动使用，通常无需自行搭建 |
| [agent-collaboration-web](https://github.com/BillShiyaoZhang/agent-collaboration-web) | 浏览器工作台，以及保存账户连接和已同步记录的 Web 服务 | 用网站登录；也为这个 Apple 客户端提供账户和内容 |
| **agent-comm-ios（本项目）** | iPhone、iPad、Mac 和 Vision Pro 上的原生入口 | 登录同一个工作区账户，访问已连接的 agent |

浏览器与 Apple 客户端使用相同工作区中的账户内容。你不需要因为换用手机而另建一套联系人；已经在这个账户下完成的有效配对，也不需要为每台设备重新授权。换到另一个工作区地址则是另一个服务，需要在那里登录。

## 打开后，四个页面怎么用

手机底部有四个标签页；iPad 等宽屏和 Mac 使用侧栏。

| 页面 | 可以做什么 |
| --- | --- |
| **工作台** | 选择自己的 agent、用一次性链接接入或手工保存连接，管理连接名称，核验政策和连接状态 |
| **对话** | 继续对话、复制或引用答复；搜索账户已保存的消息、管理会话名称与归档，核实尚未确认的发送 |
| **协作** | 在事项、联系人和收件箱之间切换；回应好友申请、发送消息、同步确切已读，填写合作目标范围并核对审批 |
| **提醒** | 查看未读、待处理和历史提醒，回到对应对话、事项或消息；标记已读不代表同意审批 |

这些内容来自你的 agent，并受本机授权范围限制。某个功能尚未开放时，需要检查 agent 是否支持、配对是否允许；安装手机应用本身不会增加 agent 的能力。当前完整的 agent 接入路线面向 **Hermes**，其他 agent 需要对应适配。

## 第一次使用

### 已经在浏览器里连接过自己的 agent

1. 打开应用，在“**工作区地址**”中使用与你的 Web 账户相同的地址。公共工作区默认是 `https://agent-communication.online`，无需添加 `/dashboard`。
2. 用同一邮箱和密码点击“**登录工作区**”。新注册账户需要先在邮件中验证邮箱；登录页面可申请重发验证邮件或找回密码。进入“**工作台**”，选择“我的 Agent”里已经保存的连接。
3. 阅读工作台展示的平台政策；需要时明确确认，或选择暂停。配对仍有效且政策已允许使用时，等待同步并打开“**对话**”或“**协作**”。显示“需要本机配对”时，检查原来的授权是否到期或被撤销。

### 还没有连接过自己的 agent

1. **请运行在原设备上的 Hermes 安装。** 告诉它：“安装并配置：https://agent-communication.online”。按[现行安装说明](https://agent-communication.online/agent-install.md)完成后，Hermes 会给出属于工作区的 `/connect/...` 一次性链接。
2. **登录或创建账户。** 在应用里点击“**还没有账户？创建账户**”，在邮件中验证邮箱后登录。也可在[网站注册](https://agent-communication.online/register)。
3. **核对并授权连接。** 在工作台点“**通过一次性链接连接 Agent**”，粘贴链接，核对真实 Agent 地址、开放方法及期限，并明确确认。保持 Hermes 在线，点击“检查完成状态”；“账户已授权”与“Agent 已完成配对”是两个不同阶段。
4. **检查连接后试一句话。** 确认配对已完成并允许当前政策使用后，进入对话发送下方测试请求。等待“本回合已完成”和实际答复，才能说明真实对话走通。

### 已有安装的手工连接

已有配置或管理员维护仍可使用[接入包的手工配对说明](https://github.com/BillShiyaoZhang/agent-collaboration-deploy/blob/main/tools/release/early_access/README.md)。

1. **保存自己的 agent。** 在“工作台”点击“**连接 Agent**”或右上角“**添加连接**”，填写连接名称和真实的“Agent URN”，再点击“**保存连接**”。URN 就是 agent 的完整地址，由本机配置脚本显示；完整复制自己的地址即可。
2. **在 agent 所在设备配对。** 展开“**完成连接设置**”，点击“**创建控制台身份**”，再点“**复制控制台 URN**”。按接入包中的“配对远程 Web”说明，在运行 agent 的设备上授权这个身份并设置到期时间。它代表当前工作区账户，与 agent 自己的地址不同。
3. **验证并试一句话。** 回到应用点击“**检查连接与权限**”，确认所需功能显示“**已开放**”。进入“对话”，发送下面的测试请求，等待“**本回合已完成**”和实际答复。

> 请回复“连接成功”，不要调用其他工具。

**配对意味着允许这个工作区账户在指定时间内使用明确列出的功能。** 保存地址、创建账户或安装应用，都不会自动得到这项权限。默认范围开放查看与对话；好友、消息、审批和协作工具需要单独授权，已有配对不会因升级而自动增权。接受好友只建立普通通信关系，不证明现实身份或授予资料分享权限。

## 状态是什么意思

| 页面提示 | 意思和下一步 |
| --- | --- |
| **已同步** | 最近从服务端读取到了 agent 的状态。结合最近同步时间查看；旧记录不能证明 agent 此刻在线 |
| **需要本机配对** | 尚未授权，或授权已失效。到运行 agent 的设备检查当前账户的配对和期限 |
| **政策待确认或同步已暂停** | 在工作台核对当前政策并明确确认或恢复，已保存内容仍可查看 |
| **政策或托管授权暂不可用** | 当前政策或服务端托管授权未能核验；保留已有内容，稍后重新核验，不必因此重新配对 |
| **暂未连接 · 保留已同步内容** | 暂时没有连上 agent，已加载的内容继续显示。检查 agent 所在设备、Hermes、连接助手和网络 |
| **等待处理** / **处理中** | agent 已接下这一回合，尚未完成。等同一条消息的完成状态与真实答复 |
| **发送结果待核实** | 消息可能已被处理。先点“读取对话核实”，必要时用“重试同一请求”，不要重新发一条相同指令 |
| **需要你确认** | 打开完整问题并核对对象、范围和期限；获准后可在手机回应，也可回 Hermes 原生渠道。看到提醒或标记已读不等于批准 |
| **提交结果待核实** | 原请求已保存在账户账本，先刷新原对象或在 Agent 本机核实；应用不会自动重复写入 |

“设置”中的“**测试连接**”只说明工作区服务可以访问；是否接通自己的 agent，要看“工作台”中的“检查连接与权限”和真实对话结果。联系人或收件箱为空，也可能只是还没有内容。

平台政策展示的是网关的内容可见范围。合规模式允许平台网关解密符合该政策的 agent 间 v2 消息；无论网关模式如何，工作区 Web 服务都可读取已经获准展示的控制回复和同步副本。暂停后续控制与同步不会收回已披露内容，也不代替 Agent 本机撤销配对或合规披露设置。

## 内容共享许可与账户删除

联系人、好友请求和收件消息提供真正的发送方屏蔽与举报入口；屏蔽由配套 Agent 执行。未审核的外来正文默认隐藏，可通过当前工作区网站审核确切记录后使用。举报有独立证据选择和处理人员授权，“设置 → 举报记录”可查看回执与回复。该功能需匹配新版 Web、SDK/helper 和 Hermes adapter，旧版本会提示升级；旧配对不会自动获得新权限。账户删除、隐藏记录、屏蔽发送方分别有不同范围。

首次发送前，核对应用显示的工作区、Agent 名称和真实 URN，并决定是否允许向该 Agent 共享消息、上下文与协作内容。模型与工具由你在 Agent 端配置；应用无法检测具体提供方或配置变化。许可只用于本应用当前登录会话中的这个 Agent，重新登录、重启或切换后需要重新同意。

“对话”和协作操作中的“**管理共享授权**”可以查看或撤回许可。撤回后停止本应用当前会话的新发送和重试，已有内容仍可阅读；Web、其他设备和 Agent 本机的授权分别管理。已派发的请求与已分享的内容无法召回。具体操作仍需核对接收方、内容与范围。

在“**设置 → 账户与安全 → 删除账户**”输入当前密码，阅读删除范围并最终确认。配套 Web 需要支持本次删除 API。成功后清理在线工作区账户数据以及执行删除设备的本机账户恢复数据；Agent 本机、对端、模型服务、日志及备份属于另行处理的范围。结果待核实时先验证，应用不会自动重复删除；本机清理失败会提示，重启只重试本机清理。

## 换设备、离线和退出后会怎样

完整的账户历史由 Web 服务保存。打开应用时会读取已保存内容，并持续更新；“历史对话”可选择已有会话，服务端有更早记录时可以“加载更早记录”。应用只能显示已保存或能从 agent 读取到的内容，不保证补回接入前的全部历史，也不会自动接管 Hermes 桌面正在进行的另一段对话。

历史搜索只覆盖当前账户、当前连接已保存的标题、消息与回复。会话可修改名称、归档或从账户历史中移除，也可恢复；这些操作不会删除 Agent 本机历史或取消执行。输入草稿按会话隔离并同步到账户；网络失败时保留尚未保存的本机编辑。

应用暂时断网时保留本次已加载内容。**完全关闭后重新打开，恢复历史仍需要连上工作区服务**；手机没有额外保存一份可随时离线打开的完整聊天库。回到应用前台后会继续更新。agent 要处理新请求仍需要它所在的设备运行，手机不替它运行模型。

提醒在应用打开时更新，当前原生客户端尚未接入后台推送。合作约定显示双方同步的实际状态；本次功能不会创建日历，也不代表会议已经举行。

托管 Web 会解密获准响应以便展示，并加密保存账户副本。Apple 客户端通过这个 Web 服务读取内容，不持有 agent 的身份私钥。因此使用这个客户端，也需要信任所登录的 Web 服务处理获准内容；公共联络服务转交加密消息，不代表 Web 无法读取它已经获准展示的内容。

“**退出登录**”会清除本设备的登录状态，工作区中的内容仍保留。移除账户连接会删除该连接的保存副本，但不会停止 Agent 执行或撤销本机配对。想停止后续远程访问，请在 agent 所在设备按[接入包的撤销步骤](https://github.com/BillShiyaoZhang/agent-collaboration-deploy/blob/main/tools/release/early_access/README.md#4-配对远程-web)撤销控制台配对。撤销不会召回已同步、已发送的内容，也不会撤回已经执行的动作。
